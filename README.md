# 🦷 Dentistry Clinic — сайт стоматологической клиники

Полнофункциональный сайт стоматологической клиники на PHP-фреймворке
Yii2: каталог услуг, специалисты, отзывы, онлайн-запись на приём и
админ-панель для управления заявками. Проект сначала создавался
в качестве дипломной работы, после этого был подстроен под пет-проект
для портфолио. Демонстрирует бэкенд-разработку: MVC, работу с базой
данных, авторизацию с ролями и администрирование контента.

## 🛠 Технологии и особенности
* **PHP 8.1 + Yii2 (basic)** - классический MVC, `ActiveRecord`,
  ActiveRecord-запросы к MySQL, генерация форм с валидацией и CSRF-защитой.
* **Авторизация и роли** - регистрация/вход, модель ролей
  (пациент / администратор) с разными сценариями интерфейса.
* **Онлайн-запись на приём** - пациент создаёт заявку из личного кабинета
  (услуга, филиал, описание проблемы), статус заявки меняется админом
  и виден в личном кабинете.
* **Админ-панель** - управление заявками (принять/отклонить) и филиалами
  клиники: отдельный модуль `admin` с формой входа и списками.
* **Отзывы** - форма с загрузкой фото и обязательным согласием на
  обработку персональных данных, отзывы отображаются на отдельной странице.
* **База данных MySQL** - 8 таблиц: пользователи, услуги, врачи, филиалы,
  заявки, статусы, роли, отзывы (`diplom.sql`).
* **Капча на форме обратной связи** - `yii\captcha` для защиты от спама.
* **Адаптивная вёрстка** - дизайн свёрстан вручную: собственный CSS
  с префиксом `dc-*`, Bootstrap 5 и jQuery, media queries от десктопа
  до мобильных экранов.
* **Дизайн** - шрифт Montserrat (Google Fonts), SVG-логотип и favicon,
  кнопки «наверх», единый стиль для сайта и админ-панели.
* **Деплой** - сайт развёрнут на реальном хостинге (PHP 8.1+, Apache,
  `.htaccess` для ЧПУ).
* **Важно** - Хостинг бесплатный (beget), поэтому страницы/стили могут
  загружаться медленно. В таком случае, пожалуйста, немного подождите.

## 📌 Цель проекта
Демонстрация навыков бэкенд-разработки на PHP и Yii2: проектирование
схемы БД и `ActiveRecord`, авторизация с ролевой моделью, CRUD в
админ-панели, работа с формами, валидацией, загрузкой файлов и
адаптивной вёрсткой без готовых шаблонов.
